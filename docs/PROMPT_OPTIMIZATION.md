# Первый этап оптимизации запросов

Выбрано сокращение общего системного контракта вместо обрезки истории или
эвристической маршрутизации по ключевым словам. История, пользовательские инструкции
и память не удаляются. Все семейства GenUI остаются доступны в каждом обычном запросе.
Сокращены дубли и длинные примеры; дизайн-режим сохраняет свой отдельный контракт.
Нужны последующие проверки качества, а не только сравнение длины строки.

Пользовательская вкладка лимитов отображает только проценты, включая accessibility
описания. Администратор видит токены и стоимость API из provider usage.cost.
Если стоимость отсутствует (включая исторические записи до миграции 008), она
помечается неизвестной, не нулевой. Никаких выдуманных тарифов/конверсий токенов.
Источник: https://openrouter.ai/docs/cookbook/administration/usage-accounting

Сводка основана на последних 200 запросах с известной стоимостью. Оценка за 100000
использованных токенов — наблюдаемая стоимость / наблюдаемые токены * 100000,
не цена подписки. Зависит от смеси моделей, входа/выхода и кэша; не включает
хостинг, налоги, комиссии, поддержку и запас на активных пользователей.

Миграция 008 расширяет существующий журнал без изменения ролей и старых списаний.
Старым запросам не присваивается искусственная историческая цена.
