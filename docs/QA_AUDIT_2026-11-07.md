## 3. Конкурентный анализ

**Где проигрываем Claude Artifacts / ChatGPT Canvas:**
1. **Код:** у конкурентов подсветка, нумерация, вкладка «Код/Превью» у артефакта; у нас моноцветный блок.
2. **Восстановление после ошибок:** Claude показывает ошибку артефакта и кнопку «Try fixing»; у нас пустой фрейм.
3. **Правка по выделению:** Canvas даёт выделить фрагмент и попросить изменить только его, плюс показывает изменения; у нас только перегенерация/версии без diff.

**Где выигрываем:**
1. **Локальный агент разработки:** работа с папкой на ПК, двойная проверка прав (TS + Rust), git-чекпоинты и откат задачи — у Canvas/Artifacts этого нет.
2. **Русские документы:** экспорт DOCX по ГОСТ (Times 14, поля, оглавление), конвейер курсовой, PDF/XLSX/PPTX одним файлом.
3. **Живое состояние артефактов:** формы и `Glow.saveState` переживают перезагрузку; плюс desktop-приложение, диктовка и прозрачный учёт токенов.
