# Облачная история (миграции применены, включение ожидает проверки входа)

Supabase — источник истины для web beta. Локальный IndexedDB больше не является основной историей при `VITE_CLOUD_DATA_ENABLED=true`. Не включать до миграций и проверки RLS реальными сессиями.

## Границы

Conversation Engine по-прежнему работает с repository port и не знает Supabase. Существующий слой `db` переключает persistence adapter. `cloudQuery` — ограниченный переходный переводчик фиксированных repository-операций; это не произвольный SQL и не долгосрочный API. При дальнейшей переработке repository переводчик заменить типизированными методами, не расширять до универсального SQL parser.

Миграция `202610110002_cloud_data.sql` добавляет отдельные таблицы с владельцем и scope. RLS проверяет `auth.uid()` и активный доступ; администратор не получает права читать чужую историю. Primary key включает владельца и предотвращает повторное добавление того же ID. Миграция `202610110003_cloud_versions.sql` добавляет серверный счётчик изменений; клиент не может менять его самостоятельно.

Изменения проверяются раз в пять секунд в видимой вкладке и при восстановлении соединения. История перечитывается только при изменении счётчика, выбранный чат сохраняется. Пока локальная генерация идёт, синхронизация откладывается. На втором устройстве ответ появляется после его сохранения, а не токен за токеном. Это не полный Realtime streaming.

## Ограничения перед выпуском

- Миграции 002–004 применены 11 октября 2026. Проверены RLS всех 16 публичных таблиц и отсутствие анонимного чтения. Транзакционный тест с имитацией JWT подтвердил запись владельцем, запрет чтения другим пользователем и запрет записи без активного доступа. Проверка двух реальных авторизованных сессий ещё не выполнена; локальные feature flags пока выключены.
- Инструкции и feedback-настройки пока локальны; общая память в cloud DB, имя/возраст в Supabase profiles.
- Файлы: облачная запись метаданных не загружает сам файл из локального пути. Нужны приватный Storage bucket и проверяемые ссылки.
- Локальная история не импортируется автоматически. Нужен явный preview импорта владельцем с отчётом.
- Миграция `202610110004_generation_lease.sql` и production AI endpoint добавляют блокировку генерации одного чата на 120 секунд с освобождением по токену владельца. Транзакционный тест подтвердил отказ второй генерации и защиту от освобождения чужим токеном. Это не блокировка редактирования и не защита локального dev proxy: конфликтующие изменения сообщений ещё требуют отдельного решения. Блокировка начинается перед запросом провайдеру, а не до записи пользовательского сообщения.
- UI widgets сейчас обновляются двумя операциями delete/insert; требуется атомарный upsert до выпуска.
- Удаление диалога выполняется несколькими запросами; нужна серверная транзакция с каскадами до выпуска.
- Cloud adapter не использует офлайн-fallback: при ошибке сохранения нужно показывать ошибку, не создавать расходящиеся копии истории.

## Проверки

`tests/cloudQuery.test.mjs` проверяет перевод существующих операций, параметры и отказ небезопасным запросам. Сборка проверяет интеграцию. Это не доказательство защиты облака: после применения миграций нужны два устройства одного аккаунта и два разных аккаунта, проверки read/write/delete, блокировки и сетевых ошибок.
