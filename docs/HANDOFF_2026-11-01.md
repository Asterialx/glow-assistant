## Как работать с пользователем
- Общение по-русски. Коммиты с `-c user.name="Claude" -c user.email="noreply@anthropic.com"`, сообщение через файл и `git commit -F` (многострочный `-m` в PowerShell 5.1 ломается), в конце `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Коммитить только нужные файлы (в дереве лежат чужие: `docs/*`, `training/`, `training.rar`, `.claude/`).
- Пуш и деплой только по прямой просьбе («пушь»). Пуш в `next` сам запускает деплой на Vercel (сайт `https://glowai-ashy.vercel.app`; проверка: хэш `assets/index-*.js` на сайте совпадает с `dist/index.html` после сборки).
- Сборка и установка: `npm run tauri:build`, потом `Glow Assistant_0.1.0_x64-setup.exe /S`. Перед установкой завершить процесс `glow-assistant` (он остаётся в фоне после закрытия окна). Проверка: размер установленного `%LOCALAPPDATA%\Glow Assistant\glow-assistant.exe` равен собранному `src-tauri\target\release\glow-assistant.exe`.
- Для правок файлов с кириллицей и не только: использовать инструмент Edit. Самописная функция замены в PowerShell дважды ломала файлы (`index.css`, `ConversationEngine.ts`: символы подменялись). Если файл испорчен: `git checkout -- <файл>` и повторить через Edit. Относительные пути в `[System.IO.File]` идут от каталога процесса, а не от `Set-Location`: один раз правка ушла не в тот репозиторий, всегда писать полные пути.
- Проверка интерфейса в браузере: Vite без авторизации `VITE_BETA_AUTH_ENABLED=false npx vite --port 1421`, режим «Код» требует подмены `window.__TAURI_INTERNALS__ = {invoke: async () => null, transformCallback: () => 0, metadata: {}}` до клика по вкладке. Сервер между шагами гаснет, поднимать заново.
