## Выводы desk research

**Проблема пользователя.** Сложная интеллектуальная работа распадается на поиск, анализ, создание документа и подготовку финального материала.

**Решение Kimi.** Продукт предлагает агентные сценарии для исследования, документов, таблиц, слайдов, сайтов и кода. В Agent mode система планирует и исполняет многошаговый процесс с инструментами; продукты результата ориентированы на готовый артефакт, а не на один ответ.

**Почему это ценно.** Пользователь может начать с результата («подготовить исследование/документ»), а не с выбора модели или набора отдельных инструментов.

**Ограничения и проверка.** Широкий набор специализированных entry points способен перегрузить интерфейс. Нужны ручные проверки навигации, статусов, ошибок, остановки, контроля агентных действий, accessibility, производительности и отзывов.

**Вывод для Glow.** Подходит ориентация на выполненную задачу и финальный материал. Не подходит ранняя продуктовая ширина «агент на всё» и каталог разных приложений: Glow должен сначала сделать один сквозной цикл надёжным и предсказуемым.
