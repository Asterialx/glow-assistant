## Выводы desk research

**Наблюдение.** Z.ai позиционирует модели и готовые agents для долгих задач, кода и мультимодальной работы. Agent API поддерживает streaming; отдельный Slide/Poster Agent соединяет генерацию содержания и готовую визуальную компоновку.

**Продуктовый смысл.** Пользователь ценит не «модель для слайдов», а снятие разрыва между созданием содержания и его превращением в пригодный к использованию результат.

**Ограничения и проверка.** Это преимущественно developer documentation. По ней нельзя оценить consumer UI, навигацию, чаты, files, ошибки, states, accessibility, производительность и отзывы.

**Вывод для Glow.** Подходит принцип завершённого результата и capability-based архитектура, в которой модель/агент заменяемы. Не подходит плодить экран или отдельный режим под каждый формат результата.
