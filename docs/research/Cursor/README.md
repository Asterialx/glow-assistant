## Выводы desk research

**Проблема пользователя.** Многошаговая задача требует вручную управлять поиском, выполнением, проверкой и исправлениями; ожидание AI непрозрачно.

**Решение Cursor.** Agent сам оркестрирует инструкции, инструменты и модель, а пользователь видит ход действий, изменения и результаты. Есть stop, безопасное руление во время работы, очередь следующих сообщений и checkpoints для обратимого эксперимента. Облачные агенты показывают статус, доказательства результата и дают takeover.

**Почему это ценно.** Пользователь формулирует желаемый результат, не последовательность технических операций. Длительная работа не блокирует дальнейшие действия.

**Риски.** Cursor прямо документирует риски удалённого окружения, секретов и автоматически выполняемых команд. Для Glow этот урок важнее конкретных agent-функций: область действия и контроль должны быть понятны до необратимого шага.

**Вывод для Glow.** Применимы прозрачный прогресс, остановка, корректировка и доказательство результата. Не применимы IDE-терминология и панель инструментов в универсальном продукте. Для не-кодовых задач нужен такой же цикл: план → выполненные шаги → результат → следующий шаг.
