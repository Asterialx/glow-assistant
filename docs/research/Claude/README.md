## Выводы desk research

**Проблема пользователя.** В длительной работе приходится снова объяснять фон задачи и искать результат среди сообщений.

**Решение Claude.** Project собирает чаты, общую knowledge base и инструкции. Артефакты выносят код, документ или интерактивный результат в самостоятельное окно рядом с беседой. Общий контекст прозрачно привязан к материалам Project, а не «телепатически» передаётся между чатами.

**Почему это ценно.** Снимается холодный старт, а пользователь редактирует результат, а не очередную реплику. Это особенно полезно для исследования, текстов и прототипов.

**Ограничения и проверка.** Не зафиксированы без ручного теста состояния streaming, ошибок, empty/loading states, клавиатурная навигация, accessibility, производительность и отзывы пользователей. Их нельзя подменять предположениями.

**Вывод для Glow.** Сохранить два принципа: контекст принадлежит задаче, а результат — отдельный управляемый объект. Не переносить названия или UI Claude и не создавать проект до того, как он действительно нужен пользователю. Glow должен уметь начать с одной задачи и ненавязчиво предложить сохранить контекст позже.
