## Выводы desk research

**Наблюдение.** Официальные материалы позиционируют DeepSeek как доступный chat/API продукт с усиленными agent-возможностями. API-документация подтверждает function calling, JSON output, prefix completion/FIM и сценарий продолжения обрезанного ответа.

**Продуктовый смысл.** Продолжение генерации — не декоративная кнопка, а восстановление работы после ограничения вывода. Это базовая capability Conversation Engine, которую Glow уже выделил отдельно.

**Ограничения и проверка.** В первичных источниках недостаточно сведений о UI: невозможно честно оценить workspace, навигацию, обработку ошибок, states, accessibility, производительность и отзывы без ручного исследования.

**Вывод для Glow.** Не строить UX вокруг особенностей одного API. Возможности конкретной модели должны скрываться за стабильным контрактом, а пользователь должен видеть понятный результат: «продолжить ответ», а не технический лимит токенов.
