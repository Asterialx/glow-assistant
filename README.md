# Glow

**Идеям нужно место.** Glow — AI-пространство для учёбы, работы и проектов: от первого вопроса до готового результата.

Общайтесь с ИИ обычным языком, добавляйте материалы в чат и продолжайте работу в одном пространстве — без сложных настроек и лишних шагов.

## Что умеет Glow

- **Ищет в интернете.** Glow распознаёт запросы, где нужны свежие данные, и показывает сайты, использованные для ответа. Подходит для поиска новостей, исследований и справочной информации.
- **Понимает ваши материалы.** Прикрепите фотографию, скан или документ и задавайте вопросы с учётом содержимого. Поддерживаются распространённые форматы изображений, PDF, Word, Excel, PowerPoint, аудио, видео и кода.
- **Готовит файлы к скачиванию.** Попросите создать документ, таблицу или презентацию — Glow подготовит Markdown, PDF, DOCX, XLSX или PPTX и покажет предпросмотр в Artifacts.
- **Помогает учиться и разбираться.** Планы подготовки, интерактивные схемы, графики, таблицы, чек-листы и калькуляторы помогают перейти от объяснения к практике.
- **Принимает голосовые запросы.** Диктуйте прямо в чате; для расшифровки Glow может использовать локальную модель Whisper.
- **Подстраивается под ваши сценарии.** Выбирайте встроенные Skills или добавляйте собственные инструкции через файл `SKILL.md`.
- **Даёт выбор модели.** В текущей конфигурации доступны GLM 5.3 Flash и Claude Haiku 5.5.

Результаты поиска и качество ответов зависят от выбранной модели и доступности сайтов и источников.

## Запуск на своём компьютере

Нужны Node.js и npm. Склонируйте проект, установите зависимости и запустите веб-приложение:

```bash
git clone https://github.com/Asterialx/glow-assistant.git
cd glow-assistant
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале (обычно `http://localhost:1420`). Чтобы подключить OpenRouter в локальном режиме, создайте `.env.local`:

```dotenv
VITE_SMARTAPI_BASE_URL=https://openrouter.ai/api/v1
VITE_PROVIDER_PROXY_ENABLED=true
OPENROUTER_API_KEY=your-api-key
```

Ключ используется локальным сервером разработки. Не добавляйте реальные ключи и другие секреты в Git или переменные `VITE_*`.

Основные команды:

```bash
npm run build       # проверить TypeScript и собрать веб-версию
npm run tauri:dev   # запустить приложение для компьютера
npm run tauri:build # собрать приложение для компьютера
```

Для Tauri понадобятся Rust и инструменты сборки для вашей операционной системы. Облачный вход и синхронизация требуют отдельной настройки Supabase; пример параметров находится в `.env.example`.
