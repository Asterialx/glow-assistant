# Glow

**AI-пространство для учёбы, идей и повседневных задач.**

Glow объединяет диалог с ИИ, работу с файлами и интерактивные инструменты в одном удобном пространстве. Можно просто задать вопрос, приложить документ или попросить подготовить готовый файл.

[Открыть Glow](https://glowai-ashy.vercel.app/) · Веб-версия сейчас работает в закрытой бете, вход — по приглашению.

## Что умеет Glow

- **Находит актуальную информацию в интернете.** Glow сам включает поиск, когда вопрос требует свежих данных, и показывает сайты, использованные в ответе.
- **Работает с файлами в чате.** Можно прикрепить фотографию, PDF, Word, Excel, PowerPoint, аудио, видео, заметку или файл с кодом — и задавать вопросы с учётом его содержимого.
- **Создаёт готовые документы.** По запросу можно подготовить Markdown, PDF, DOCX, XLSX или PPTX, посмотреть файл в Artifacts и скачать его.
- **Помогает учиться и планировать.** В Glow есть планы подготовки, интерактивные схемы, таблицы, графики, чек-листы и небольшие инструменты прямо в чате.
- **Поддерживает голосовой ввод.** Текст распознаётся во время речи; Glow также может использовать локальную модель Whisper для расшифровки записи.
- **Сохраняет повторяемые сценарии.** В Skills можно выбрать готовый навык или импортировать самостоятельный файл `SKILL.md`.

Доступны GLM 5.3 Flash и Claude Haiku 5.5; список зависит от серверной конфигурации. Качество ответов и поиска зависит от выбранной модели и доступности источников.

## Запуск на своём компьютере

Нужны Node.js и npm. Склонируйте проект, установите зависимости и запустите веб-приложение:

```bash
git clone https://github.com/Asterialx/glow-assistant.git
cd glow-assistant
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале (обычно `http://localhost:1420`). Чтобы подключить OpenRouter в локальном режиме, создайте `.env.local`:

```dotenv
VITE_SMARTAPI_BASE_URL=https://openrouter.ai/api/v1
VITE_PROVIDER_PROXY_ENABLED=true
OPENROUTER_API_KEY=your-api-key
```

Ключ используется локальным сервером разработки. Не добавляйте реальные ключи и другие секреты в Git или переменные `VITE_*`.

Основные команды:

```bash
npm run build       # проверить TypeScript и собрать веб-версию
npm run tauri:dev   # запустить приложение для компьютера
npm run tauri:build # собрать приложение для компьютера
```

Для Tauri понадобятся Rust и инструменты сборки для вашей операционной системы. Облачный вход и синхронизация требуют отдельной настройки Supabase; пример параметров находится в `.env.example`.
